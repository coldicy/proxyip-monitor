📖 使用手册

一、平均总延迟
当配置了自定义探针时，每次探测的总延迟 = 官方探针 + 所有自定义探针的平均值。
如果没有自定义探针，则只使用官方探针。

二、离线判定
只要任意一个探针当次不通，就判定为离线；包括官方探针和任意自定义探针。

三、柱状图
柱状图高度表示最近探测的平均总延迟，越高越慢。
点击任意柱子可以查看该次探测中每个探针的单独详情：总延迟、TCP、TLS、HTTP/源站延迟、HTTP 状态码、失败原因。

四、列表平均值
列表显示优质判定窗口内的平均值：平均总延迟、平均TCP、平均TLS、平均HTTP/源站延迟。

五、GitHub 与复制
GitHub 上传和复制节点备注均使用平均总延迟。
