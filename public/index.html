📖 手册

1. 目标

长期监测并筛选“当前最适合你”的 Cloudflare IP 或第三方反代 IP。

2. 延迟四段

  • TCP：你到节点的 TCP 连接耗时
  • TLS：TLS 握手耗时
  • 源站：节点到 Cloudflare / 源站响应耗时
  • 总延迟：TCP + TLS + 源站

3. 在线 / 优质

  • 在线：官方探针成功；如配置自定义探针，则至少一个自定义探针也要成功
  • 优质：最近 N 次样本足够、达标率达标、平均总延迟不超过上限

4. GitHub

  • 上传文件默认包括：proxyip_all.txt、proxyip_best.txt
  • 如果识别到 Cloudflare IP / Proxy IP，还会上传 cf_best.txt / proxy_best.txt
  • Token 需要 repo Contents 读写权限

5. ip.txt

  • 纯 IP:端口，例如：104.16.1.1:443
  • 域名:端口，例如：example.com:443
  • 远程列表 URL，例如：https://example.com/ip.txt
