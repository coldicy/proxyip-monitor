📖 使用手册

一、它是什么

Proxy Monitor 是一个自托管的 Cloudflare ProxyIP / 反代节点长期监测与优选工具，采用 IP 主键模型：节点以 IP 命名，域名仅作为“发现来源”。

二、IP 主键模型（核心）

  • 单元 ID = ip:port。多个域名解析到同一 IP 会合并为一个节点，信息行「来源」列出所有域名。
  • 每个 IP 每轮只测试一次，不会出现“同IP一个在线一个离线”的矛盾。
  • 上传 GitHub 天然不重复，上传数 = 优质数。

三、屏蔽与清除（v18 统一语义）

  • 清除 = 屏蔽：无论自动清理还是手动删除，都会把该 ip:port 写入屏蔽名单并记入清除记录。
  • 屏蔽的 IP 不会被域名二次解析复活，也不会因重新写进 ip.txt 而显示。
  • 解除屏蔽的唯一方式：设置 → 🗑️ 清除记录 → 清空记录。
  • 自动清理：离线超 自动清理天数 触发；手动删除：勾选删除。

四、在线判定（三重验证）

  • ① 官方探针：测 TCP/TLS 延迟并获取 数据中心/地区/出口IP。
  • ② 强制测速：下载512KB，失败重试1次；零速/无速度=离线。
  • ③ 自定义探针：返回403=SNI白名单/1034假反代，判离线。

五、指标说明

列含义
TLS 平均 / 平均速度优质窗口内成功样本的平均值（反映近期表现）
TLS 最新 / TCP 最新最近一次检测快照
成功率窗口内成功次数占比
状态条🟩达标 未达标 ⬜失败，悬浮看单次明细
来源该 IP 被哪些域名解析到
淘汰原因离线节点红字说明

六、优质判定

窗口内每次检测都达标（成功+TLS≤上限+速度≥下限）的比例 ≥ 达标率阈值（默认1）才算优质。

七、GitHub 同步

  • 格式 ip:port#地区 | TLS平均 | 平均速度Mbps；多文件 all + 地区；手动/变动/定时三种上传，日志闭环。

八、常见问题

  • 为什么同IP只有一行？IP主键聚合，来源里看域名。
  • 删除/清理的IP会复活吗？不会（已屏蔽）。要恢复请清空清除记录。
  • 把已清除IP写回ip.txt会显示吗？不会，屏蔽优先；清空记录后才显示。
