📖 使用手册

一、延迟自洽（v32）

官方探针与自定义探针各自在同一次请求内测全 TCP/TLS/源站/总，组内恒等：总 = TCP + TLS + 源站。所有指标在优质窗口内取平均，双组分别展示，可直接相加验证。

二、延迟柱状图

近 N 次状态条高度随延迟变化（越高越慢），颜色=达标/超标/失败，悬浮看该次四段明细。

三、探针分工

官方探针：TCP/TLS 握手 + 元数据 + 初步筛选。
自定义探针(多个)：真实回源延迟 + 真伪闸门，取成功探针平均。
